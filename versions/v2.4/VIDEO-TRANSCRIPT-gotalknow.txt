VIDEO TRANSCRIPT — GoTalk Now AAC app demonstration (Step Up AT)
Source: https://youtu.be/C5lLOE6sGRg  (duration 5:06, 115 caption segments)
Fetched 2026-08-20 for Talk Tiles template work. This is the reference app whose
behavior Talk Tiles should match. Key behaviors called out in the video:

- THREE page styles: standard, express (speech bar), scenes.
- Page editor shows a customizable page template with page number + bottom toolbar:
  home (house icon -> home screen), grid-size selector (1..36 locations/page),
  background/border color settings, express-page toggle (enables speech bar at top
  that plays selected words IN SEQUENCE when pressed), all-pages button, plus sign.
- Standard page: action occurs when the location is pressed; tap each button one at
  a time to set background or border color; type text anywhere in the button; add
  image from camera/photo library or symbol set; auditory cue = recorded voice OR TTS.
- Scene pages: built around a single photo/image; INVISIBLE hotspots arranged over
  people/objects; each hotspot plays speech (recorded or TTS), music, or video;
  created via plus sign -> blank scene page -> set background image (library/device/photo)
  -> small plus signs to add as many hotspots as needed.
- Water bottle / hand sanitizer / elevator are just the demo's scene photos.
